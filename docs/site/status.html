Operator steps a merge does not fully cover

  • Migrations run in deploy.yml after a green CI run. If that job fails, run npm run db:migrate with DIRECT_URL by hand from a trusted machine.
  • deploy.yml pushes only the bdworker service. The TrueForge service on Zerops is pushed by hand, and a failed worker push in the deploy run also needs a manual zcli push.
  • GitHub App permissions and events, private vulnerability reporting per repository, and the optional registry variables are switched on by a person, as listed in AGENTS.md.
