Motion gallery

Each tile loops a real keyframe or transition, using the values in app/globals.css and the components named under it. The Reduce motion switch stops loops and slides, like the OS setting.

Each tile loops a proposed mobile motion with the values measured from Variant C (screens/c.css and c.js). The core easing is the desktop curve, cubic-bezier(.23, 1, .32, 1), and the desktop keyframes (step-in, approval-halo, mascot-float, shimmer-text) run in the C screens with the same values. Nothing here is built into an app; the app is iOS and Android only.
