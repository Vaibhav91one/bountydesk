“A triage agent that cannot declare victory by itself.” The canary, not the model, decides whether a report reproduced.
OAuth signs in the user. The GitHub App grants repo access. The server binds each delivery to the target profile.
No defender fixture, no reproduced verdict. The report becomes analysis only, and a human decides the next move.
The target is pinned before the run: Vaibhav91one/juice-shop at the exact v17.3.0 commit.
The negative control runs first. A passing script is only useful after the control proves the oracle can stay quiet.
TrueForge can drive the browser, shell, and logs. It still cannot narrate the verdict.
The evidence packet carries the target hash, canary outcome, oracle adapter, and outbound payload hash.
The close calls come to the review queue with states, severity, evidence, and the exact action needed.
Scope is enforced at the capability boundary. Clone, deploy, and egress never come from report text.
Report state and job execution stay separate, so leasing problems cannot become user-facing verdicts.
READY means the target answered its health check. It never means reproduced, severe, or safe to deliver.
Similar reports are candidates, not auto-closures. Only exact delivery replays do nothing.
The reviewer gets the raw record: run log, oracle result, target profile, hashes, and signed payload.
The human gate signs the exact outbound words. Change the text, and the hash no longer matches.
One approved comment ships. The token is discarded, and exact replays are ignored.
